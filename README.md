# Frontend AI Capstone

A Frontend AI Engineering capstone project focused on building clean, accessible, and responsive web interfaces.

## Overview

This repository is the home for my capstone work in frontend development. The goal is to apply modern frontend practices—semantic HTML, maintainable CSS, and modular JavaScript—while exploring AI-assisted development workflows.

**Status:** Early development. Application code and setup instructions will be added as the project progresses.

## Tech Stack

- HTML, CSS, JavaScript
- Node.js
- Git & GitHub
- Cursor / Claude Code (AI-assisted development)

## Development Principles

- Semantic, accessible markup
- Responsive, mobile-friendly layouts
- Modular file and component structure
- Minimal dependencies; prefer simple, maintainable solutions
- [Conventional Commits](https://www.conventionalcommits.org/) for commit messages
