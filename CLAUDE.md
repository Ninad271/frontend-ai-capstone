\# Project Instructions



\## Project Overview



This repository contains my Frontend AI Engineering capstone project.



The project should follow clean, maintainable, accessible, and scalable frontend development practices.



\## Tech Stack



\- HTML

\- CSS

\- JavaScript

\- Node.js

\- Git

\- GitHub

\- Cursor / Claude Code



\## Development Principles



\- Write clean, readable, and maintainable code.

\- Keep files and components modular.

\- Avoid unnecessary dependencies.

\- Prefer simple solutions over unnecessary complexity.

\- Use semantic HTML.

\- Follow accessibility best practices.

\- Build responsive interfaces.

\- Keep styling organized and maintainable.

\- Do not modify unrelated files when completing a task.



\## Git Conventions



Use Conventional Commits for all commits.



Examples:



\- feat: add authentication page

\- fix: correct mobile navigation

\- docs: update README

\- refactor: simplify API utility

\- chore: update dependencies

\- test: add login tests



\## AI Assistant Guidelines



Before making significant changes:



1\. Understand the existing project structure.

2\. Explain the proposed approach when appropriate.

3\. Make the smallest reasonable change.

4\. Avoid modifying unrelated files.

5\. Review the changes after completing the task.

6\. Ask for clarification if requirements are ambiguous.



\## Code Quality



\- Use meaningful variable and function names.

\- Avoid duplicated code.

\- Keep functions focused.

\- Handle errors appropriately.

\- Consider responsive design.

\- Consider accessibility.

\- Keep dependencies to a minimum.



\## Documentation



Keep README.md updated when project setup, features, architecture, or usage instructions change.



\## Security



\- Never expose API keys, passwords, tokens, or other secrets.

\- Keep environment variables in `.env` files.

\- Never commit `.env` files to Git.
